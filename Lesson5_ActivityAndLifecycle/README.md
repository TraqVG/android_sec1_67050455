# Lesson 5 - Activity and Lifecycle (Pomodoro App)

Pomodoro configuration lab completed through the Parcelable step. The project demonstrates:

- View Binding
- UI setup and six +/- click listeners
- Activity lifecycle (`onStart` / `onStop`)
- persistence with `SharedPreferences`
- navigation with an explicit `Intent`
- Bundle extras
- a `@Parcelize` `Config` data class passed to `TimerActivity`

Open this folder directly in Android Studio, sync Gradle, and run the `app` configuration.
